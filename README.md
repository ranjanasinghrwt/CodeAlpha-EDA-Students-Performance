# CodeAlpha - Exploratory Data Analysis (EDA)

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Students Performance in Exams dataset using Python.

The objective is to explore student scores, identify patterns, understand relationships between subjects, and analyse academic performance.

## Dataset
- **Source:** Kaggle – Students Performance in Exams
- **Records:** 1,000 students
- **Original Features:** 8 columns

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Kaggle Notebook

## Analysis Performed
1. Data inspection and statistical summary
2. Missing-value and duplicate checks
3. Gender-wise performance analysis
4. Test preparation analysis
5. Parental education and lunch analysis
6. Correlation analysis
7. Score distribution visualisation
8. Outlier detection using IQR
9. Average score calculation
10. Student performance categorisation

## Key Learning Outcomes
- Data cleaning and exploration
- Statistical analysis using Pandas
- Data visualisation using Matplotlib and Seaborn
- Identifying patterns and relationships in datasets
